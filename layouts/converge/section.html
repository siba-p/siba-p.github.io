Details

    Why Converge?

    Consecutive simulation frames are correlated, the start of a run is rarely equilibrated, and slow drifts hide in noisy data. The naive standard error ignores all three. In our tests on correlated data it covered the true mean only 38% of the time, against the 95% it claims.

    Converge chooses the equilibration point, measures how correlated the data are, and reports an error bar that holds up. With the same data its 95% intervals covered the true mean 94.8% of the time.

    Method

    • Equilibration: t₀ that maximises the number of uncorrelated samples (Chodera, JCTC 2016), cross-checked with MSER-5.
    • Autocorrelation: FFT autocorrelation with Sokal's automatic window; g = 2τint.
    • Block averaging: Flyvbjerg–Petersen with automatic plateau detection.
    • Stationarity: first-half versus second-half z-test and a linear-trend test.
    • Planning: SEM ∝ 1/√T gives the run length needed for a target error.

    The same algorithms are available as a Python package: github.com/siba-p/converge. The web app and the package give identical numbers.
