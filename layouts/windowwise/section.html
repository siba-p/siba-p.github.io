How is the design derived?

On a locally flat profile a harmonic window samples a Gaussian, and two neighbours a distance {{ transform.ToMath `d` (dict "output" "htmlAndMathml") }} apart overlap by

{{ transform.ToMath `\sigma = \sqrt{k_B T / k}, \qquad O = 2\,\Phi\!\left(-\frac{d}{2\sigma}\right).` (dict "displayMode" true "output" "htmlAndMathml") }}

A slope {{ transform.ToMath `F'` (dict "output" "htmlAndMathml") }} shifts every window by {{ transform.ToMath `F'/k` (dict "output" "htmlAndMathml") }}. Keeping that below half a spacing gives the force constant

{{ transform.ToMath `k \;\geq\; \frac{1}{k_B T}\left(\frac{|F'|_{\max}}{z}\right)^{2}, \qquad z = -\Phi^{-1}\!\left(\tfrac{O}{2}\right).` (dict "displayMode" true "output" "htmlAndMathml") }}

What am I looking at?

                  
Blue: the potential of mean force from WHAM, with a ±1σ band from block-bootstrap resampling of each window. Orange dashed: the Gaussian-process (GP) profile built only from each window's mean force k(c − ⟨ξ⟩), with its 95% Bayesian band. Where the two agree, the result is robust. Where the GP band widens, the data are thin. Stars mark the windows that active learning would run next.

              

                
What am I looking at?
Each curve is one window's histogram, shaded light to dark along ξ. A healthy run tiles the coordinate with overlapping bumps. Gaps between bumps, or a bump sitting far from its restraint centre (dot), are what WHAM cannot fix.

              

                
What am I looking at?
The overlap between each pair of neighbouring windows (sum of the minimum of their normalised histograms). Pairs below the dashed threshold are coloured, and marked ! (warning) or ✕ (critical).

    Why WindowWise?
    
          
    Umbrella sampling fails quietly. Windows that are too far apart, or springs too soft for a steep wall, leave holes in the free-energy profile that WHAM smooths over. Usually you only find out after the compute is spent. WindowWise brings design, post-mortem and repair into one place.
    
          
    Python package and CLI: pip install git+https://github.com/siba-p/windowwise. Validated against an analytic Morse-type PMF: WHAM RMSE 0.19 kJ/mol; GP 0.18–0.86 kJ/mol with 41 to 11 windows.
    
        
    
        
    
          
    Method
    
          
    Bias (GROMACS pull code) and WHAM self-consistency
    
          {{ transform.ToMath `U_i(\xi) = \tfrac{1}{2} k_i (\xi - \xi_i)^2` (dict "displayMode" true "output" "htmlAndMathml") }}
          {{ transform.ToMath `P(\xi) = \frac{\sum_i n_i(\xi)}{\sum_i N_i\, e^{\beta f_i - \beta U_i(\xi)}}` (dict "displayMode" true "output" "htmlAndMathml") }}
          {{ transform.ToMath `e^{-\beta f_i} = \sum_{\xi} P(\xi)\, e^{-\beta U_i(\xi)}, \qquad F(\xi) = -k_B T \ln P(\xi)` (dict "displayMode" true "output" "htmlAndMathml") }}
          
    Errors: block bootstrap of each window, block length {{ transform.ToMath `2g` (dict "output" "htmlAndMathml") }}. Diagnostics: neighbour overlap, drift {{ transform.ToMath `|\langle\xi\rangle_i - \xi_i|` (dict "output" "htmlAndMathml") }}, and {{ transform.ToMath `N_{\mathrm{eff}}` (dict "output" "htmlAndMathml") }} per window.
    
          
    GP umbrella integration (ML): each window gives an exact estimate of its mean force
    
          {{ transform.ToMath `\left\langle \frac{\partial A}{\partial \xi} \right\rangle_i = k_i \left(\xi_i - \langle \xi \rangle_i\right), \qquad \operatorname{Var} = k_i^2\, \frac{g_i\, \sigma_i^2}{N_i}` (dict "displayMode" true "output" "htmlAndMathml") }}
          
    used as derivative observations of a Gaussian-process prior {{ transform.ToMath `A \sim \mathcal{GP}\big(0,\, s^2 e^{-(\xi-\xi')^2/2\ell^2}\big)` (dict "output" "htmlAndMathml") }}, with {{ transform.ToMath `s, \ell` (dict "output" "htmlAndMathml") }} from the marginal likelihood. Active learning places the next window where the posterior variance of {{ transform.ToMath `\partial A/\partial \xi` (dict "output" "htmlAndMathml") }} is largest.
