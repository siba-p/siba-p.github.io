From g(r) to thermodynamics

Kirkwood–Buff integrals turn radial distribution functions into preferential binding, activity coefficients and partial molar volumes, but only if the finite size of the box is handled properly. Load your RDFs, or explore an example where the right answer is known:

Why KBkit?

The running Kirkwood–Buff integral does not converge in a closed, finite simulation box: even an ideal gas appears to avoid itself. KBkit computes the raw integral alongside two finite-size corrections, shows whether they agree, and only then turns the result into thermodynamics.

Python package and command line: pip install git+https://github.com/siba-p/kbkit. The web app and the package give identical numbers.

Method

Running integral

{{ transform.ToMath `G_{ij}(R) = 4\pi \int_0^{R} \left[ g_{ij}(r) - 1 \right] r^2 \, dr` (dict "displayMode" true "output" "htmlAndMathml") }}

Ganguly–van der Vegt correction of the closed-box RDF

{{ transform.ToMath `g_{ij}^{\mathrm{GvdV}}(r) = g_{ij}(r)\, \frac{N_j \left(1 - V_r/V\right)}{N_j \left(1 - V_r/V\right) - \Delta N_{ij}(r) - \delta_{ij}}` (dict "displayMode" true "output" "htmlAndMathml") }} {{ transform.ToMath `V_r = \tfrac{4}{3}\pi r^3, \qquad \Delta N_{ij}(r) = \rho_j\, G_{ij}(r)` (dict "displayMode" true "output" "htmlAndMathml") }}

Krüger–Vlugt finite-volume integral, extrapolated to the thermodynamic limit

{{ transform.ToMath `G_V(L) = \int_0^{L} \left[ g(r) - 1 \right] 4\pi r^2 \left(1 - \tfrac{3x}{2} + \tfrac{x^3}{2}\right) dr` (dict "displayMode" true "output" "htmlAndMathml") }} {{ transform.ToMath `x = \tfrac{r}{L}, \qquad L\,G_V(L) = G_\infty\, L + F` (dict "displayMode" true "output" "htmlAndMathml") }}

Binary mixture (c = cosolvent, w = solvent), with {{ transform.ToMath `\Delta = G_{cc} + G_{ww} - 2G_{cw}` (dict "output" "htmlAndMathml") }}

{{ transform.ToMath `\left(\frac{\partial \ln a_c}{\partial \ln x_c}\right)_{T,p} = \frac{1}{1 + \rho\, x_w \Delta}` (dict "displayMode" true "output" "htmlAndMathml") }} {{ transform.ToMath `\bar V_c = \frac{1 + \rho_w (G_{ww} - G_{cw})}{\eta}, \qquad \kappa_T = \frac{\zeta}{\eta\, k_B T}` (dict "displayMode" true "output" "htmlAndMathml") }} {{ transform.ToMath `\eta = \rho_w + \rho_c + \rho_w \rho_c \Delta` (dict "displayMode" true "output" "htmlAndMathml") }} {{ transform.ToMath `\zeta = 1 + \rho_w G_{ww} + \rho_c G_{cc} + \rho_w \rho_c \left(G_{ww} G_{cc} - G_{cw}^2\right)` (dict "displayMode" true "output" "htmlAndMathml") }}

Preferential binding of cosolvent c to solute p
